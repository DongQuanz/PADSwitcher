PADSwitcher 1.21.1 sửa lỗi khi mở máy và các trạng thái lệch giữa PADSwitcher với Codex.

- **Hết hộp lỗi khi vừa bật máy:** mỗi lần mở bản portable giải nén vào thư mục riêng, nên
  nhiều cửa sổ VS Code mở lại cùng lúc không còn xóa `PADCodex.exe` của nhau (lỗi
  "Thiếu cầu nối PADCodex.exe"). Chỉ một cửa sổ mở PADSwitcher, các cửa sổ khác chờ kết nối.
- **Chịu được lúc Windows còn bận:** PowerShell/WMI chậm, tệp bị phần mềm diệt virus giữ
  tạm hoặc Codex khởi động lâu được thử lại thay vì báo lỗi. Gateway đã bật tự kết nối lại.
- **Lỗi có mã và nhật ký:** hộp lỗi ghi mã lỗi và đường dẫn `startup-error.log` trong
  `%APPDATA%\PADSwitcher`.
- **Bớt bất đồng bộ:** không còn lượt Codex "kẹt" chặn đổi tài khoản hay dừng gateway; hồ sơ
  không bị coi là "CLI đang chạy" sau khi khởi động lại máy; làm mới token không làm Codex
  desktop hoặc CLI dùng chung phiên bị đăng xuất; đồng bộ nền không ghi đè lần chuyển desktop.
- **Nhẹ hơn khi nằm trong khay:** chỉ kiểm tra kết nối VS Code/JetBrains/desktop liên tục khi
  cửa sổ đang hiện.
- **Nhận đúng extension mới:** VS Code, Cursor và Windsurf bản hiện tại lại được nhận diện và
  hiển thị là đã kết nối.

Thoát bản cũ từ khay hệ thống, mở bản mới rồi Reload Window trong VS Code một lần. Hội thoại
và tài khoản đã lưu được giữ. Bản portable chưa ký số, đi kèm checksum SHA-256.

Bản phát hành này do [@DongQuanz](https://github.com/DongQuanz) thực hiện trên nền
PADSwitcher của Anh-Duc Phan.

PADSwitcher 1.21.1 fixes errors right after sign-in and states that drifted between
PADSwitcher and Codex.

Each launch of the portable build now unpacks into its own folder, so editor windows
restored together after a reboot no longer delete each other's `PADCodex.exe` (the
"missing PADCodex.exe bridge" error or a Windows error box). Only one window opens
PADSwitcher; the others wait for its connection. Slow PowerShell/WMI, files briefly held
by antivirus and a slow Codex start are retried, and an enabled gateway reconnects on its
own. The error box shows the error code and the path of `startup-error.log` in
`%APPDATA%\PADSwitcher`.

A turn whose thread Codex has unloaded no longer blocks switching or stopping. A reused
process id after a reboot is no longer taken for a running CLI. Refreshing a session that
the desktop app or an open CLI shares reuses a rotation that process already made instead
of signing it out, and a background sync no longer overwrites a desktop switch. Integration
status is polled continuously only while the window is visible. Current VS Code, Cursor and
Windsurf extensions are detected and shown as connected again.

Exit the old version from the tray, launch the new portable and reload the VS Code window
once. Conversations and saved accounts are kept. The executable is unsigned and includes a
SHA-256 checksum.

PADSwitcher.
